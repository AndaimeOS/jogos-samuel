# Samuel Surfers

Corrida de três faixas. Fonte em `src/`, pacote servido em `_privado/jogos/samuel-surfers/`.

```bash
npm install
npm test
npm run build
npm run teste:ipad
```

O `teste:ipad` sobe o portal PHP e usa o Playwright WebKit no perfil de iPad.
A arte está explicada em `ARTE.md`. A revisão do MetroDash está em `ORIGEM.md`.
